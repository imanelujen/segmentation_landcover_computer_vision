# Environnement de développement

## Configuration matérielle

- Processeur : Intel Core Ultra 5 225U
- Mémoire RAM : 14 GiB
- GPU : Intel Graphics intégrée
- Système : Ubuntu 26.04.1 LTS

## Configuration logicielle

- Python : 3.12.16
- Gestionnaire : uv
- Framework : PyTorch
- Entraînement : Kaggle GPU
- Interface : Streamlit

## Architecture d'exécution

Le développement et le prétraitement des données
sont effectués localement.

L'entraînement des modèles U-Net et SegFormer
est réalisé sur Kaggle avec accélération GPU.
